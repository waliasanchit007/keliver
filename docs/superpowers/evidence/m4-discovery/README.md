# M4 discovery instrumentation

Does making the portal tools **visible** change whether an agent uses them?

**Three arms with three repetitions each — nine runs on one fixture, not nine
independent defect cases.**

Supported finding: on this fixture all nine participants produced the expected
screen fix, and none invoked a portal tool, including the three runs with the
tools listed upfront. Each of the nine outputs was scored individually; all
passed, against the unfixed control's failure.

What it does **not** settle: why the earlier deferred participants did not use
the tools. The listed participants' explanations are self-reports consistent
with their traces, and a trace shows only that no tool was called, never why.
Case 2's *not discovered* versus *considered and declined* stays open for the
deferred runs.

The separate forced-use exercise
([`../m4-case2/DIAGNOSTIC.md`](../m4-case2/DIAGNOSTIC.md)) shows the queries
expose useful binding information. It does not show that using them improves
outcomes.
