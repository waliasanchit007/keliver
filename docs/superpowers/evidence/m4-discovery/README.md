# M4 discovery instrumentation

Does making the portal tools **visible** change whether an agent uses them?

On this fixture: **no.** Nine runs across three arms, zero portal invocations,
including three runs where the tools were listed directly in the model's tool
set (manipulation-checked, not assumed). All nine produced the identical
correct fix, independently scored PASS.

This closes the question case 2 left open — *not discovered* versus
*considered and declined* — in favour of **declined**. It says nothing about
whether the tools help when used; see
[`../m4-case2/DIAGNOSTIC.md`](../m4-case2/DIAGNOSTIC.md) for that, separately.
