Do NOT set KELIVER_USE_MAVEN_LOCAL.

HOW TO RUN IT ON THE ANDROID EMULATOR
An emulator is running and a generic Keliver host app is already installed.
It loads your app's bundle over HTTP. Port 8080 is free.

  1. Serve your build (leave it running in the background):
       ./gradlew serveDevelopmentZipline --console=plain &
     Wait until this returns 200:
       curl -s -o /dev/null -w '%{http_code}' http://localhost:8080/manifest.zipline.json
  2. (Re)start the host so it reloads your bundle:
       adb -s emulator-5554 shell am force-stop dev.keliver.portaldevice
       adb -s emulator-5554 shell am start -n dev.keliver.portaldevice/dev.keliver.portaldevice.host.MainActivity
     Give it ~15 seconds.
  3. Read what is on screen:
       adb -s emulator-5554 shell uiautomator dump /sdcard/ui.xml
       adb -s emulator-5554 shell cat /sdcard/ui.xml | grep -oE 'text="[^"]+"'
     Screenshot:
       adb -s emulator-5554 exec-out screencap -p > shot.png
  4. Tap something. Get its bounds from the uiautomator dump, then:
       adb -s emulator-5554 shell input tap <x> <y>

After changing Kotlin you must rebuild AND restart the host (steps 1-2) for the
change to reach the device. If a gradle command fails with a permissions error
about a lock file, add --no-daemon.

The cart screen shows a Subtotal line and a Total line.

  * Each "Add item" tap adds one $12.00 item to the cart.
