The Basket screen never binds the summary label to the presenter's state.

- `src/jsMain/kotlin/screens/home.kt:17` — the summary `StyledText` is `text = "0 items"`, a hardcoded string literal. The `HomeScreenBindings.summary` field (declared at `home.kt:28`) is never read by the screen, so the label is frozen at "0 items" regardless of how many times "Add item" is tapped.
